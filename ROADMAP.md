# Roadmap

- **0.1**: CPU tensor core, autograd, neural-network basics, optimizers, data loading, state serialization.
- **0.2**: API hardening, broader operators, stronger numerical and module coverage.
- **0.3**: Backend contract refinement and first accelerator backend.
- **0.4**: Public Nexora IR specification and tracing experiments.
- **0.5**: Compiler and IR lowering.
- **0.6**: Portable model format.
- **0.7**: Distributed execution.
- **0.8**: Transformer primitives and quantization.
- **0.9**: Hardware plugin SDK and inference-runtime boundaries.
- **1.0**: Stable public API and compatibility contract.
